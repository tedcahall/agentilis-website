Agentic Product Development: A Real Estate Lead-Response Product, Built in Weeks

Two real estate professionals, a broker and a young independent agent breaking into the business, asked whether one product could serve them both. Their problem: new leads go cold while agents are out showing homes. The product was specified in Markdown, and an AI engineering agent built it from the spec. The first running server was live in AWS 3 hours after the spec was written. Today the product is about 56,000 lines of Java, covering the agent portal, the broker portal and the back-office administration console.

What the Product Does
  1. Monitors the agent's email inbox continuously
  2. Recognizes a genuine new lead and ignores newsletters, receipts and duplicates
  3. Replies in under 60 seconds, in the agent's own words, with a phone number and booking link
  4. Texts the agent the lead's number, so one tap starts the call
  5. For brokers, distributes leads across the team: round-robin, weighted, or assigned by hand
External Services
  • Gmail API: secure access to the agent's inbox, with a push notification the moment a new email lands
  • Smarty: finds property addresses in the lead email and verifies them against USPS data
  • Google Address Validation: a second, independent check of every address against USPS data
  • Amazon Comprehend: detects people's names in the email text
  • Telnyx: text messages in both directions, plus a lookup that confirms a phone number is real and what kind of line it is
  • Twilio: a second text-message provider
  • SendGrid: system email, with bounce tracking
How It Was Built
  1. The two customers described the problem and how they work
  2. The product was specified in Markdown: market requirements, product requirements and technical design
  3. James, the AI Java engineer, read the spec and built the code: agent portal, broker portal and back-office console
  4. New spec iterations were written in Markdown, and James implemented each one
  5. The external services were connected: Gmail, address and name verification, phone lookup, text messaging and email
  6. A test harness sent fake leads, built from 600 fake names and fake property addresses in the formats lead providers like Zillow use, to real inboxes and checked each one end to end
  7. Every change ran through the automated tests before it was merged
Guardrail

A lead is only answered automatically when the system is sure. Several independent extractors read each lead's name, phone, email and address, and a value is accepted only when they agree and a verification service confirms it. Every property address is checked by two independent address verifiers, and every phone number is looked up. Anything less goes to a review queue. A repeat inquiry is recognized as a duplicate and not contacted twice, and a text message that cannot be routed safely is held for review.
