Case Studies

AI Agents Run Their Own Project Portfolio, and a Human Sets the Priorities

In our own operations, a team of 24 AI agents works across 23 projects. Keeping track used to mean files spread across many folders and status pieced together by hand. Now every project starts from one command, lives in a standard folder, and shows up on a board. A script sends an hourly pulse of what is blocked, in progress and waiting. Each morning the agents suggest priorities, and the human approves them with a one-word answer.

What the Agents Do
  1. Start every project with one command that builds the folders, writes the project summary and log, and adds the registry row
  2. Keep each project in the same layout: the human's source material, which agents never edit, a work folder for each agent, and versioned deliverables that are never overwritten
  3. Record decisions and handoffs as dated, signed log entries, and hand off work by file path so there is only one copy
  4. Move cards honestly: into an active column when work starts, to Blocked with a reason when stuck, and a checked box when done
  5. Check every board every 15 minutes during working hours, and wake the project-management agent only when something new needs action
  6. Send the human an hourly pulse, 8 a.m. through 7 p.m., grouped by project: blocked, in progress, priority and new items. A script builds it, with no AI cost
  7. At 8:00 each morning, count the priority cards on 20 boards. The owner agent of any board with fewer than 3 suggests up to 3 more, each with a one-line reason
  8. At 9:00, send the human one numbered list. The human answers by number, and the project-management agent applies only what was approved
  9. Drafted a status report every Monday morning and Friday afternoon across the projects: what was delivered, what is due next, open risks, and anything that needs the human at the top. A marketing agent polished the wording, and the chief-of-staff agent reviewed it before it went out. When the hourly pulse made the report redundant, the human retired it
The Hard Cases
  • Suggestions that stay fresh: the agents suggest only cards that still need a decision. Cards that already carry the priority label and cards checked complete are left out, so every suggestion is worth a look.
  • Every owner gets the morning request: agents that check their queue on a schedule pick it up there, and the rest get a direct nudge, so the request reaches every owner agent.
  • Two kinds of boards: projects run on Trello or GitHub Projects, and the pulse reads both with the same column rules. Each board is read on its own, so one board never holds up the pulse.
  • A pulse that stays readable: card titles are kept under 50 characters so each one prints as a single line. Detail goes in the card, not the title.
Guardrail

The board is a record, not a work queue. An agent that finds a card does not start on it. Work begins when the human asks. Only the human adds or removes the priority label, and only the human snoozes a card. Agents suggest priorities but never apply them. New operations cards land in a triage list, where a reviewing agent and the human decide what matters. A project stays active until the human closes it.

What It Means for You

How much of your week goes to finding out where things stand?

Status meetings and chasing updates take time from the work itself. Agents can keep the projects organized, report status every hour, and bring you a short list of priorities each morning. You still make every call.
