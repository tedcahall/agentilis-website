Automated CSV Processing for the Washington DC Region SCCA

After every race weekend, official race result files arrived across multiple emails. Often from different people. Each file had to be downloaded, renamed to match the system-of-record, and then uploaded one at a time, published and checked. It took hours - which meant a human put it off for days... Now an agent does it in minutes upon the emails' arrival.

What the Agent Does
  1. Waits for emails. Finds the one with results
  2. Downloads the results files in the right locations
  3. Checks downloaded data files for required fields and data consistency
  4. Looks up the correct file naming information from the system
  5. Renames the files in the format the system-of-record needs
  6. Uploads the official race results
  7. Checks the live site to see that all results were published correctly
Guardrail

Files are inspected to ensure they meet standards for required data fields and consistency. Files that do not alert the proper sources via email automatically. No human in the loop.
