Case Studies

A Class Planner That Builds Every Set to the Rules, for Jazzercise NRV

At Jazzercise NRV, a fitness studio in Virginia's New River Valley, instructors build new class sets all the time. A set is an ordered list of routines. Each position calls for a certain kind of routine, the class has to land on the clock, and the format's rules decide what can go where. It was all done by hand, about 90 minutes a week for each of the studio's 10 instructors. An AI agent team built a class planner instead. The instructor picks a class format and describes the feel. The planner builds a complete set, checks it against the rules, and hands it back to lock, swap, reorder and save.

What the Agents Do
  1. Load the class format the instructor picks, with its slot pattern, length and equipment
  2. Read the feel the instructor describes in plain words, such as "high-energy 90s pop"
  3. Place any routines the instructor pre-selected, up to half the slots in the class
  4. Use an AI model to choose a routine for every remaining slot from the catalog, matched to the feel
  5. Check the set against all 25 rules: opener first, closer last, the cardio curve, strength grouping, freshness, equipment and length, and try again up to 3 times if it fails
  6. Show the set with each routine's length, format, equipment, the reason it was chosen, and a chart of the class's energy curve
  7. Let the instructor lock, swap, reorder and save, and check every edit against the slot it lands in
  8. Import each new monthly collection and keep the catalog matched to the official routine notes
The Hard Cases
  • Routines with a fixed place on the curve: some routines may only sit on the way down from the cardio peak. The planner allows at most one in the cardio block, and only in the last light-medium slot.
  • A pre-selected routine that cannot fit: the planner names the routine and the reason, and asks the instructor to remove it and try again. It never drops a choice quietly.
  • A catalog that drifts from the source: in one audit, 1,108 routines differed from the official routine notes. Agents logged every change, made 2,461 corrections with 0 failures, and re-checked: 0 differences remained.
  • A slow answer from the AI model: after 120 seconds the instructor sees a clear "try again" message instead of a frozen screen, and the failure is logged for diagnosis.
Guardrail

The instructor decides what gets taught. The planner hands back a starting set, and every routine can be locked, swapped, reordered or removed. Edits are checked, so the opener and closer stay in place and a swap offers only routines that fit the slot. Class length is a warning, not a block: the instructor can accept it. The app is invite-only, and each instructor's saved sets are private. Agents build and test every change on a separate development copy, and the live app changes only when the owner approves the release.

What It Means for You

Which planning job in your business lives in one person's head?
