Case Studies · Format A: The Brief

A decade-old Java system running in AWS, modernized and refactored by an AI agent team.

Two Java applications have run the Washington DC SCCA racing series' official scoring since 2015. They worked flawlessly. But only one person understood them, and they were running old versions of the OS, the servers, the DB, and the Java code.

An agent team refactored each layer of the stack locally first, then upgraded and validated them in production in the cloud. No rewrite. Zero downtime. Now new features can be designed and bugs can be fixed, coded, tested, and deployed to the cloud by texting agents while at the track.

Hard to Add / Manage Issue List at Track. Managing new feature requests from the track was difficultAgent GitHub Issue Creation. A simple text to any agent can create a fully documented Issue in GitHub to be solved later by a software agent.

Why Agents

Agents are very low cost, they scale up, and the budget was not going to increase. Agents were the only solution and provided a 10-100x acceleration of the required platform upgrades, code refactoring, which led to additional feature development and diagnostics capability, and eventual automation of the back-office features.

These would have never been completed by a single busy owner with no additional budget.
