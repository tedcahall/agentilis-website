Security Hardening and a First-Attempt CASA Pass for an App That Reads Customers' Gmail

AgentREBoost reads real estate agents' Gmail inboxes to catch new leads. Before Google allows that in production, the app must pass a Cloud Application Security Assessment (CASA). An AI agent team ran the penetration tests, fixed what they found, and walked the owner through every CASA requirement.

What the Agents Did
  1. Ken set up OWASP ZAP penetration testing: weekly scans of the website and app, plus full authenticated scans for each of the four user roles
  2. The full scans overwhelmed the original server, so Ken built a dedicated scan server with Ansible. Scans that never finished now take about 20 minutes
  3. James fixed each finding: anti-CSRF tokens, cross-site scripting, error pages that leaked details, session handling, and input that could crash a page
  4. Every finding was logged with its fix, and every false positive with the reason, ready for the CASA assessor
  5. Ken read the CASA specification, wrote a 14-step plan, and compared assessment labs on price and process
  6. Ken and James walked the owner through every CASA security requirement and changed the code to comply
  7. James answered the 15-page CASA questionnaire, checking every claim against the code. 7 gaps were found and built before submission
  8. Changes for CASA included Gmail access cut to read and send only, account deletion with a 30-day grace period, automatic deletion of mail data after 180 days, an audited reason before staff can view a mailbox, sign-in lockout and rate limits, two-step sign-in for staff, sessions ended on password change, logs scrubbed of tokens, encrypted backups, and a dependency scan with zero known vulnerabilities
The Result

AgentREBoost passed Google's CASA assessment on the first attempt, in under a week. The assessor had expected it to take months.

Guardrail

Penetration tests never touch production. Every scan runs against a throwaway copy of the app with scrubbed data, and text messages are stripped from every copy. The scanner is blocked from closing accounts, deleting Gmail data or resetting passwords, and it stops itself if memory, disk or database growth crosses a limit.
